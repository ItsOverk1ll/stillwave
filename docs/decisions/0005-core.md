# ADR 0005: Core: Rust workspace, SQLite, Lofty, Symphonia

Status: accepted (Phase 0)

## Context

Scanning, decoding and the library must be fast, memory-safe and shared by every platform.

## Decision

A Rust workspace (`stillwave-core`, `-db`, `-audio`, `-plugins`). SQLite via rusqlite (bundled, WAL, FTS5). Lofty for tags and Symphonia for decoding arrive in Phase 1.

## Consequences

Bundled SQLite means identical behaviour on every OS (including FTS5). Measured: 50,000-track search is 1 to 8 ms (docs/benchmarks.md).
