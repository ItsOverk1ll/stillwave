# ADR 0008: IDs: UUIDv7 and a change log

Status: accepted (Phase 0)

## Context

Devices must create data offline and merge it later without ID clashes or lost edits.

## Decision

Every entity has a UUIDv7 (time-ordered) ID. Every user-data write also appends a `change_log` row (entity, operation, changed fields, hybrid logical clock timestamp, device ID) in the same transaction.

## Consequences

Sync in Phase 4 can replay the log. A small write overhead and storage cost. Time-ordered IDs also keep B-tree inserts local.
