# ADR 0001: Project name: Stillwave

Status: accepted (Phase 0)

## Context

The project needed a name that is not confusable with an existing product.

## Decision

The project is called **Stillwave**.

## Consequences

Consistent branding in the app id (`org.stillwave.app`), crates (`stillwave-*`) and docs. Renaming later is possible but touches every crate, the app id and the update channel.
