# ADR 0004: UI: React and TypeScript on Vite

Status: accepted (Phase 0)

## Context

A large UI (library, playlists, search, settings) needs a mainstream, well-supported stack.

## Decision

React with strict TypeScript, built by Vite. ESLint (strict, type-aware), Prettier, Vitest. Plain CSS with variables for theming; no component library yet.

## Consequences

Large hiring and contributor pool. Heavy UI work stays off the Rust audio path by design.
